# Forge concepts deck

Open the local concept reference:

```sh
open examples/concepts-deck/index.html
```

Twelve slides covering the Forge vocabulary: the eight identity principles, the
compile-then-run pipeline, authoring concepts, compile concepts, the IR node
taxonomy, runtime concepts, the run lifecycle, the port inventory, the
distinctions that are commonly collapsed, and one worked example that touches
every concept in order.

Terms follow the handbook — [MASTER_SPEC](../../docs/MASTER_SPEC.md),
[004-architecture](../../docs/004-architecture.md),
[006-runtime](../../docs/006-runtime.md), and
[007-workflow-compiler](../../docs/007-workflow-compiler.md). Examples are drawn
from the documented demo scenarios in
[016-demo-scenarios](../../docs/016-demo-scenarios.md).

This deck describes the specified design. It is documentation, not a runnable
demonstration.
